# 蓮のわんわん総選挙 FINAL 応援企画サイト

## ファイル構成
- `index.html` : サイト本体（HTML/CSS）
- `assets/` : 蓮の写真

## GitHub Pagesで公開する方法
1. GitHubで新しいリポジトリを作成（例：`ren-thank-you-campaign`）。
2. このフォルダ内の `index.html` と `assets` フォルダをリポジトリ直下にアップロード。
3. リポジトリの **Settings → Pages** を開く。
4. **Deploy from a branch** を選択し、Branch を `main`、フォルダを `/ (root)` にして保存。
5. 公開URLが表示されるまで少し待つ。

## 公開前に確認すること
- プレゼント内容・参加条件・日付が最新か確認する。
- 実際のSNSアカウントや問い合わせ先を掲載したい場合は、必要なリンクを追記する。
- 公開リポジトリに本名・住所・個人用メールアドレスなどを入れない。
